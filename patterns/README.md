# Patterns

Screens agents build often, each described once and built on the [foundations](../foundations/README.md) and [tokens](../tokens/tokens.css). Read the pattern that matches your task after the foundation files; when no pattern matches, compose from the foundations.

| Pattern | For |
|---|---|
| [settings.md](settings.md) | Account, notifications, sharing, data and preferences |
| [list-detail.md](list-detail.md) | Browsing a collection of text items and opening one: mail, notes, tasks, tickets |
| [landing-page.md](landing-page.md) | A page that presents a product |

Each pattern is tried by a fresh agent on a new product before it counts as done. More patterns (forms and sign-in, navigation, dialogs and sheets, empty and error states, tables and dashboards) come one at a time.

Each file follows the same order: **When** → **Anatomy** → **Rules** → **Narrow screens** → **States** → **Web translation** → **Don't** → **Related**.

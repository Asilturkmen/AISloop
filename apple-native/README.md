# apple-native

Guidance for apps built **only for Apple platforms** (iOS, iPadOS, macOS, watchOS, visionOS) with native frameworks such as SwiftUI or UIKit. Use it when the project you are working on is one of these; you can tell from its code and configuration (e.g. an Xcode project with no web or Android target).

Everything outside this folder is general AISloop guidance for any project, web and cross-platform included.
